# Knowledge Management

Capturing and protecting knowledge are two different jobs: `akm remember`,
`akm import`, `akm bundle add`, and LLM wikis turn what an agent or teammate
learns into searchable assets any agent can find, while `akm env` and
`akm secret` hold configuration and credentials under a stricter guarantee —
values never appear in akm's structured output. This page has moved; the
content now lives in two focused pages.
