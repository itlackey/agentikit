Release notes for #957 (0.9.15)

`akm improve`'s six shipped scheduled task templates
(`src/assets/tasks/improve/*.yml`, `src/assets/tasks/core/improve.yml`) now
run with `--require-engines`, next to `--skip-if-locked` where that flag was
already present. This only affects NEW installs and NEW `akm setup` task
seeding from this release forward — it does not rewrite task files an
existing install already materialized under `~/.config/akm/tasks/` (or a
stash's `tasks/` directory).

If your scheduled `improve` task predates this release and you want the same
protection — abort loudly (exit 78) instead of silently skipping processes
when an engine/credential is unavailable in the task's own environment — add
`--require-engines` to that task's `run:` command yourself, then run
`akm task sync` to apply the edit.
